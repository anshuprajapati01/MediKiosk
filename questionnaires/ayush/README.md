# AYUSH Questionnaires

AYUSH case-taking in MediKiosk is **configuration-driven** and must support physician-defined fields without inventing medical rules.

This includes (but is not limited to) the traditional **Dashavidha Pariksha** (ten-fold examination) framework:
- Purusha Pariksha (patient examination)
- Vyadhi Pariksha (disease examination)
- Dushya Pariksha (tissue / dosha examination)
- Desha Pariksha (habitat examination)
- Bala Pariksha (strength examination)
- Kala Pariksha (seasonal / temporal examination)
- Anala Pariksha (digestive fire examination)
- Prakriti Pariksha (constitution examination)
- Vaya Pariksha (age examination)
- Satva Pariksha (mental strength examination)

Configuration files define field labels, input types, units, display order, and branching logic. Physicians may add custom fields, sections, and sequences appropriate to their practice. The system does not enforce medical rules; it only captures, stores, and presents structured data for physician review.
